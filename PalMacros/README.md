# Pal Macros

Макросы на все заклинания паладина для WoW Forever (интерфейс 16001). Версия — в заголовке окна и во вкладке «Настройки»; после каждого обновления аддон пишет в чат «обновлён: старая → новая».

Открыть окно: `/pal`, кнопка у миникарты (подхватывается HidingBar), значок в списке аддонов или «Настройки → Модификации → Pal Macros» (там кнопки «Открыть настройки» и «Открыть макросы»).

Вкладки: «Макросы», «Бой» (очередь атакующей кнопки), «Фразы» (тексты по благословениям и язык), «Классы» (выбор умной кнопки), «Игроки» (журнал благословлённых), «Настройки» (фразы в чат, канал, шанс, пауза, кнопка у миникарты, версия).

## Макросы
Вкладка «Макросы» показывает все изученные заклинания по группам. Нажмите на значок или перетащите его — макрос создастся (сначала в макросах персонажа, потом в общих) и окажется на курсоре, кладите на панель. «Создать все» создаёт макросы для всего сразу.

- Названия заклинаний берутся из игры (русский клиент), ранг в макросе не указан — после изучения нового ранга у учителя макрос сам использует старший.
- Новые заклинания аддон находит сам при изучении. Заклинания Forever, которых нет в таблице (Удар Света, Печать ярости, Бастион тамплиера и т. п.), попадают в группу «Новые»: атакующие получают автопоиск цели, помогающие — «мышь → цель → себя».
- Макросы, созданные аддоном, обновляются автоматически. Если вы изменили макрос вручную, аддон его не трогает (статус «изменён вручную»).

Шаблоны:
- Благословения, лечение, очищение: мышь → дружеская цель → себя.
- Благословение защиты/свободы, Возложение рук: сначала прерывают каст; Alt — снять эффект с себя.
- Жертвенность, Божественное вмешательство: только на другого (мышь → цель).
- Искупление: мёртвый под мышью → мёртвая цель.
- Правосудие, Экзорцизм, Молот гнева и т. п.: если нет живой вражеской цели — берётся ближайший враг, включается автоатака.
- Молот правосудия, Покаяние, Изгнание нежити: враг под мышью → цель → ближайший враг, без автоатаки.
- Божественный щит, Божественная защита, Праведное неистовство: Alt — снять.
- Конь: повторное нажатие спешивает.
- Готовая связка «Щит+Камень» (щит, второе нажатие — Камень возвращения).

## Кнопка «Бой»
Одна кнопка на весь бой: если нет врага в цели — берёт ближайшего, включает автоатаку и пробует заклинания очереди сверху вниз (если первое на перезарядке или не подходит — срабатывает следующее). По умолчанию очередь рекомендуемая: Правосудие → Удар Света и другие новые удары Forever → Удар воина → Молот гнева → Экзорцизм, и она сама пополняется при новом уровне и новых заклинаниях. Во вкладке «Бой» порядок можно менять (^ v), убирать (x) и добавлять (+) — тогда очередь становится «своей»; «Сбросить на рекомендуемую» возвращает автоматический режим. Макрос ограничен 255 байтами — окно показывает, сколько заклинаний поместилось.

## Фразы при благословениях
Готовые фразы по умолчанию — на английском (дворфийский акцент); кнопка «Язык фраз» во вкладке «Фразы» переключает на русский. При благословении (отдельным макросом или умной кнопкой) персонаж произносит случайную дворфийскую фразу. Во вкладке «Фразы» для каждого благословения — свой список, одна строка = одна фраза. Подстановки: `{name}` — имя цели, `{class}` — класс, `{spell}` — заклинание. Можно выключить отдельные благословения, сменить канал (Сказать / Крикнуть / Эмоция / Группа), задать шанс и паузу, чтобы не повторяться тому же игроку. Себя по умолчанию не поздравляет.

Фраза уходит в момент нажатия (иначе игра блокирует «Сказать»), поэтому аддон заранее проверяет: цель в радиусе, нет глобального перезаряда, вы не кастуете и не верхом.

## Журнал благословлённых игроков
После каждого успешного благословения (макросом, умной кнопкой или из книги заклинаний) игрок записывается в журнал: имя, класс, уровень, раса, сколько раз и какими благословениями, когда впервые и последний раз. Вкладка «Игроки» (или `/pal players`): поиск по имени, классу или расе; для выбранного игрока — поле с именем для копирования, «Найти (/who)», «В друзья», «Шёпот», «Удалить» (с Shift). Журнал хранится в настройках аддона и общий для всех персонажей.

## Умное благословение
Значок вверху вкладки «Макросы». Наведите мышь на игрока (или возьмите его в цель) и нажмите — паладин выберет благословение по классу. Shift — большое (Greater) версия. Порядок по классам настраивается во вкладке «Классы» (по два варианта: берётся первый изученный). Работает вне боя — в бою пользуйтесь отдельными макросами.

## Команды
`/pal` — окно, `/pal settings` — настройки, `/pal version` — версия, `/pal players` — журнал игроков, `/pal all` — создать все макросы, `/pal update` — обновить, `/pal say` — вкл/выкл фразы, `/pal test` — показать в своём чате, что выберет умная кнопка.
