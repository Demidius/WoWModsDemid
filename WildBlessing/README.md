# My Blessing

Аддон для друида в WoW Classic Anniversary / Forever (интерфейс 16001). При входе создаёт макрос персонажа `WildMark`, который накладывает «Знак дикой природы» на дружественного живого персонажа под курсором. Откройте настройки значком у миникарты или командой `/wild settings` и перетащите значок макроса из окна на панель действий. Макрос также доступен через `/macro`. Если создать его не удалось, освободите место в макросах персонажа и введите `/wild macro`.

Аддон отслеживает успешное применение именно «Знака дикой природы» через события заклинания, в том числе обычным заклинанием без макроса. В момент применения имя получателя должно быть доступно аддону и совпадать с видимой целью, целью под курсором, участником группы или рейда. Если игра скрывает имя или цель неоднозначна, аддон не записывает игрока и сообщает об этом. Учитываются только игроки, включая самого друида; питомцы и NPC не учитываются. Каждый новый игрок получает постоянный номер, его имя сохраняется в список. Повторное наложение не создаёт запись и не готовит сообщение. Команда `/wild players` показывает сохранённые имена. Ранее записанные только по идентификатору игроки сохраняют свои номера; их имена добавляются при следующем распознавании без повторного сообщения. Счётчик хранится отдельно для каждого персонажа между входами. Отсчёт начинается с установки аддона: ранее полученные знаки восстановить невозможно.

Макрос `WildMark` пытается отправить благословение в канал «Сказать» в момент нажатия, до подтверждения заклинания. Поэтому сообщение может уйти даже при неудачном применении; номер сохраняется только после успешного применения. Если игра заблокировала отправку, аддон подготовит сообщение в строке чата для подтверждения клавишей Enter. Если отправка не подтверждена чатом, текст доступен через `/wild next`. Изменённые вручную макросы не перезаписываются: перед `/cast` добавьте строку `/run WildBlessingAnnounce()`. При применении обычным заклинанием аддон готовит сообщение для отправки через Enter.

В окне настроек можно посмотреть число игроков, открыть отдельный список имён и номеров кнопкой «Список игроков», добавить или удалить благословения и перетащить макрос на панель. Игроки со старым сохранением без имени отображаются с пометкой «Имя не сохранено». Значок у миникарты можно перемещать мышью.

Благословения чередуются по кругу. В аддоне есть пять готовых вариантов; собственные сохраняются между входами отдельно для каждого персонажа.

- `/wild list` — показать пронумерованный список текстов в своём чате.
- `/wild add Elune guide you, {имя}! #{номер}.` — добавить вариант. Обе подстановки обязательны; текст ограничен 180 байтами, чтобы поместиться в игровое сообщение.
- `/wild remove 2` — удалить вариант с указанным номером из списка. Должен остаться хотя бы один текст.
- `/wild` — число уникальных игроков, `/wild macro` — создать макрос, `/wild next` — открыть следующее ожидающее благословение.

Аддон не изменяет существующий макрос `WildMark`.

Внутреннее имя папки `WildBlessing` сохранено для совместимости с сохранённым счётчиком и пользовательскими текстами.

Установка: скопируйте папку `WildBlessing` в `_forever_/Interface/AddOns`, перезапустите игру или выполните `/reload`. На экране выбора персонажа включите аддон.
