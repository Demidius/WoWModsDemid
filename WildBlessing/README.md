# My Blessing

Аддон для друида в WoW Classic Anniversary / Forever (интерфейс 16001). При входе создаёт макрос персонажа `WildMark`, который накладывает «Знак дикой природы» на дружественного живого персонажа под курсором. Откройте настройки значком у миникарты или командой `/wild settings` и перетащите значок макроса из окна на панель действий. Макрос также доступен через `/macro`. Если создать его не удалось, освободите место в макросах персонажа и введите `/wild macro`.

Аддон реагирует на успешное наложение или обновление именно «Знака дикой природы», в том числе обычным заклинанием без макроса. Учитываются только игроки, включая самого друида; питомцы и NPC не учитываются. Каждый новый игрок получает постоянный номер, повторное наложение сохраняет тот же номер. Счётчик хранится отдельно для каждого персонажа между входами. Отсчёт начинается с установки аддона: ранее полученные знаки восстановить невозможно.

После успешного наложения аддон открывает строку чата с готовым благословением в канал «Сказать». Нажмите Enter, чтобы отправить его. WoW ограничивает автоматическую отправку в этот канал в открытом мире, поэтому отправку подтверждает игрок. Если строка чата уже открыта, сообщение ждёт в очереди; завершите ввод и введите `/wild next`. Очередь хранится только до перезагрузки интерфейса.

В окне настроек можно посмотреть число игроков, добавить или удалить благословения и перетащить макрос на панель. Значок у миникарты можно перемещать мышью.

Благословения чередуются по кругу. В аддоне есть пять готовых вариантов; собственные сохраняются между входами отдельно для каждого персонажа.

- `/wild list` — показать пронумерованный список текстов в своём чате.
- `/wild add Elune guide you, {имя}! Mark #{номер}.` — добавить вариант. Обе подстановки обязательны; текст ограничен 180 байтами, чтобы поместиться в игровое сообщение.
- `/wild remove 2` — удалить вариант с указанным номером из списка. Должен остаться хотя бы один текст.
- `/wild` — число уникальных игроков, `/wild macro` — создать макрос, `/wild next` — открыть следующее ожидающее благословение.

Аддон не изменяет существующий макрос `WildMark`.

Внутреннее имя папки `WildBlessing` сохранено для совместимости с сохранённым счётчиком и пользовательскими текстами.

Установка: скопируйте папку `WildBlessing` в `_forever_/Interface/AddOns`, перезапустите игру или выполните `/reload`. На экране выбора персонажа включите аддон.
