# Vendor or Auction

Аддон помогает разбирать сумки WoW: Forever и использует цены и скорость продаж TradeSkillMaster. Он не продаёт и не выставляет предметы автоматически.

Введите `/voa` или нажмите кнопку с монетой, чтобы открыть окно разбора. Вкладки: «Торговцу» ($), «Аукцион» (A), «Хранить» (K), «Проверить» (?). Наведите на строку или предмет, чтобы увидеть объяснение.

Кнопки «Хранить» и «Торговцу» задают личное правило для всех предметов с этим ID. «Авто» удаляет правило. Предметы из списка хранения и предметы заданий имеют приоритет; персональные вещи без личного правила попадают в «Проверить». Для целей активных заданий используются данные журнала и, если доступна, база Questie. Не все цели могут распознаваться; при сомнениях сохраните предмет вручную. Предметы для профессий автоматически не определяются: добавьте нужные вручную в список хранения.

Кнопка «Обновить» перечитывает содержимое сумок и активные задания и пересчитывает рекомендации по доступным в TSM данным; сканирование аукциона и загрузку цен она не запускает. Рекомендации также обновляются при изменении сумок и заданий. В настройках окна можно изменить размер значков и финансовые пороги. Скорость продаж регулируется ползунком или вводом числа; комиссию и размер значков можно также менять кнопками со стрелками. `/voa settings` открывает настройки напрямую. Расчёт на штуку: цена аукциона TSM после комиссии минус цена торговцу. Для расчёта и подсказки используется DBRecent — оценка TSM по последнему обработанному снимку аукциона; скорость — DBRegionSaleRate. DBRecent не является ценой конкретного лота или данными в реальном времени. Если DBRecent недоступна, средние цены и минимальный выкуп не подставляются. Для порога минимальной выгоды прибыль за штуку умножается на количество неперсональных предметов с одинаковой строкой TSM во всех обычных сумках и сумке для реагентов текущего персонажа. Варианты одного ID с разными строками TSM считаются отдельно. Значки Baganator показываются только для текущих сумок, а не для банка или других персонажей. При скорости продаж TSM ниже порога рекомендуется торговец независимо от размера выгоды; при отсутствии скорости показывается «Проверить», если другие правила не дают рекомендации. В окне разбора при наведении на строку показана выгода за стопку. Сумма аукциона в окне учитывает только стопки с известной ценой, после комиссии, без залога. Источник цены может быть устаревшим: аддон не определяет её возраст. Залог, возможность выставить конкретную вещь и время продажи не гарантируются; при отсутствии необходимых данных показывается «Проверить».

## Подсказка предмета

Без Shift аддон дополняет стандартное название предмета значком категории, количеством всех таких предметов в сумках и ценами торговца и аукциона за штуку и за всё количество. Цена аукциона показана до комиссии; для персональных предметов аукцион недоступен. Используется DBRecent — цена по последнему обработанному снимку TSM. Если данных нет, цена не показывается. Деньги отображаются значками монет. При скорости продаж ниже настроенного порога цена аукциона выделяется красным: это предупреждение о низкой скорости продаж, а не гарантия, что предмет не продастся. Полная подсказка TSM по Shift требует отдельной локальной доработки TSM: его встроенные настройки версии на момент изменения не поддерживают Shift. Обновление TSM может удалить эту доработку. Личные настройки TSM и данные не входят в этот аддон.

В краткой подсказке цены выровнены в отдельных столбцах «За шт.» и «За всё». Для сокращения повторов аддон один раз включает в Syndicator показ его инвентарных подсказок по Shift; эту настройку можно изменить в Syndicator.

Рядом с названием показаны уровень предмета и требуемый уровень персонажа через дробь: например, «Lv. 17 / 12». Прочерк означает, что требования нет. Цены расположены в небольшой таблице за штуку и за всё количество. Краткая подсказка скрывает рыболовный блок OneCast; при Shift доступна подробная подсказка.
