# Vendor or Auction

Аддон помогает разбирать сумки WoW: Forever и использует цены и скорость продаж TradeSkillMaster. Он не продаёт и не выставляет предметы автоматически.

Введите `/voa` или нажмите кнопку с монетой, чтобы открыть окно разбора. Вкладки: «Торговцу» ($), «Аукцион» (A), «Хранить» (K), «Проверить» (?). Наведите на строку или предмет, чтобы увидеть объяснение.

Кнопки «Хранить» и «Торговцу» задают личное правило для всех предметов с этим ID. «Авто» удаляет правило. Предметы из списка хранения и предметы заданий имеют приоритет; персональные вещи без личного правила попадают в «Проверить». Для целей активных заданий используются данные журнала и, если доступна, база Questie. Не все цели могут распознаваться; при сомнениях сохраните предмет вручную. Предметы для профессий автоматически не определяются: добавьте нужные вручную в список хранения.

Кнопка «Обновить» перечитывает содержимое сумок и активные задания и пересчитывает рекомендации по доступным в TSM данным; сканирование аукциона и загрузку цен она не запускает. Рекомендации также обновляются при изменении сумок и заданий. В настройках окна можно изменить размер значков и финансовые пороги. `/voa settings` открывает настройки напрямую. Расчёт на штуку: цена аукциона TSM после комиссии минус цена торговцу. Используется DBMinBuyout, затем DBMarket; скорость — DBRegionSaleRate. Для порога минимальной выгоды прибыль за штуку умножается на общее количество одинаковых неперсональных предметов во всех обычных сумках и сумке для реагентов текущего персонажа. Правило медленной продажи и процента выгоды действует отдельно. В подсказке показана общая выгода. Сумма аукциона в окне учитывает только стопки с известной ценой, после комиссии, без залога. Источник цены может быть устаревшим: аддон не определяет её возраст. Залог, возможность выставить конкретную вещь и время продажи не гарантируются; при отсутствии необходимых данных показывается «Проверить».

## Подсказка предмета

Без Shift аддон дополняет стандартное название предмета значком категории, количеством всех таких предметов в сумках и ценами торговца и аукциона за штуку и за всё количество. Цена аукциона показана до комиссии; для персональных предметов аукцион недоступен. Используется минимальный выкуп TSM, а если он недоступен — средняя региональная цена продажи. Деньги отображаются значками монет. Полная подсказка TSM по Shift требует отдельной локальной доработки TSM: его встроенные настройки версии на момент изменения не поддерживают Shift. Обновление TSM может удалить эту доработку. Личные настройки TSM и данные не входят в этот аддон.

В краткой подсказке цены показаны в формате «за штуку / за всё». Для сокращения повторов аддон один раз включает в Syndicator показ его инвентарных подсказок по Shift; эту настройку можно изменить в Syndicator.
