# Buff Reminder

Аддон для WoW Classic Anniversary (_forever_, интерфейс 16001). Показывает иконки отсутствующих эффектов вне боя: сытость, «Прилив сил» от спального мешка и эффекты, добавленные вручную. Наведите курсор на иконку, чтобы узнать, какого эффекта не хватает. Напоминание о «Приливе сил» скрывается на максимальном уровне. Оно отслеживает сам эффект от спального мешка, отдельно от накопленного опыта за отдых.

Открывайте настройки ярлыком у миникарты или командой `/brm`. В настройках можно включить или выключить напоминания и добавить эффекты по их точному названию или ID заклинания. Эффекты можно удалить из списка; длинный список прокручивается. Сравнивается название или ID самой положительной ауры, отображаемой на персонаже. Если название введено вручную, оно должно совпадать с названием эффекта в клиенте игры, включая регистр. Если игра не может определить иконку эффекта, отображается знак вопроса.

Перемещайте иконки напоминаний с зажатым Shift. Ярлык у миникарты также можно перетащить мышью. Настройки и положение сохраняются отдельно для каждого персонажа.

Команды: `/brm`, `/brm food`, `/brm rest`, `/brm on`, `/brm off`, `/brm add ID`, `/brm remove ID`, `/brm list`. Установите папку BuffReminder в _forever_/Interface/AddOns и перезапустите игру. После обновления установленного аддона выполните `/reload`.
