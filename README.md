# Аддоны Демида для WoW

Здесь хранятся аддоны, которые мы создаём для игры. Каждый аддон размещается в отдельной папке и содержит собственный файл `.toc`.

## Аддоны

- [My Auction Pawn Upgrades](AuctionPawn/) — фильтры и сравнение улучшений Pawn на аукционе WoW: Forever.

## Установка на другом компьютере

1. Открой страницу репозитория и нажми **Code → Download ZIP**.
2. Распакуй архив и найди папку нужного аддона с файлом `.toc` внутри.
3. Скопируй эту папку в папку игры `Interface/AddOns` соответствующей версии WoW. В некоторых установках путь включает дополнительную папку версии игры.
4. Перезапусти игру или выполни команду `/reload` и проверь список аддонов на экране выбора персонажа.

Важно: в `AddOns` должна лежать папка аддона, внутри которой сразу находится его `.toc`, а не папка всего репозитория.

## Обновление

Когда в репозитории появится новая версия, скачай архив снова и замени папку нужного аддона. GitHub хранит файлы, но сам по себе не устанавливает и не обновляет их на компьютерах. Настройки аддонов обычно хранятся отдельно в папке `WTF` и не переносятся вместе с кодом.

## О совместимости

Проверяй, что версия аддона совместима с клиентом WoW, который ты используешь. Инструкции для отдельных аддонов будут добавляться рядом с ними.
